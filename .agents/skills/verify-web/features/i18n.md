# Languages

## What exists

English (base) and Polish through Paraglide JS. Messages live in `apps/web/messages/{en,pl}.json`; the compiled `apps/web/src/paraglide/` is generated and gitignored. The header has a language `<select>`. The choice is stored in `localStorage` under `PARAGLIDE_LOCALE`; without it the browser's preferred language wins, then English.

## How to reach it

Any page. The select is in the header next to "Sign out".

## Drive

1. Pick "Polski". The page reloads (Paraglide's `setLocale` does that) and every label is Polish: "Zadania", "Dodaj", "Wyloguj".
2. Check the counter with different counts. Polish has three forms:
   - 1: "Zostało 1 zadanie"
   - 2 to 4, 22 to 24: "Zostały 2 zadania"
   - 0, 5 to 21, 25: "Zostało 5 zadań"
     Add or tick todos to reach 1, 2 and 5 left.
3. Submit an empty todo and an invalid sign-in. The errors are Polish too.
4. Switch back to "English" so the next run starts in the base language, or use a fresh profile.

## What usually lies

- **The plural counter.** English has two forms, Polish three. A message that only has `one` and `*` reads right in English and wrong in Polish for 5 or 12. Check 1, 2 and 5.
- **A key added only to `en.json`.** Paraglide falls back to nothing useful, and the English screen looks fine. Every new key goes to both files; switch to Polish and look for English words.
- **Stale compiled messages.** The Vite plugin recompiles on change. If a new message is missing, restart `pnpm dev` before you debug the component.
- **Text from the server.** better-auth error reasons come back in English and are placed inside a Polish sentence. That is known; do not translate them by string matching.
