# Todos

Your todo list is private. Nobody else who signs in can see it.

## Add a todo

Type what needs doing and choose **Add**. A title can be 1 to 200 characters.

## Mark a todo as done

Tick the box next to it. A done todo stays in the list, crossed out, until you remove it. Untick the box to bring it back. The count under the list shows how many todos are not done.

## Remove a todo

Choose the bin icon next to it. Removing is permanent: there is no archive and no undo.
